# 抽選モニター（tyu-sen）

ポケモンカードの抽選・予約・販売情報を、登録したWebサイトやRSSから自動収集し、一覧表示するローカル向けWebアプリです。

## 機能概要

- **監視サイト管理** — 店舗・情報源の登録、URL設定、有効/無効、手動巡回
- **キーワード検出** — ページ本文から抽選情報の可能性を広めに検出
- **抽選情報一覧** — カード/テーブル表示、フィルター、ステータス管理
- **信頼度スコア** — 0〜100点で抽選情報らしさを表示
- **重複判定** — 同一/類似情報の統合・「類似情報あり」表示
- **アプリ内通知** — 新着、締切前、未応募のリマインド
- **手動登録** — URL貼り付けで解析・登録
- **除外キーワード** — 買取・中古などをマーク（完全削除しない）
- **ダッシュボード** — 新着・未確認・締切件数などのサマリー

## 起動方法

### 必要環境

- Node.js 18 以上
- npm

### セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

初回起動時に `data/tyu-sen.db`（SQLite）が自動作成され、サンプル店舗16件が登録されます（URLは未設定・無効状態）。

> **Vercel 本番環境**では SQLite ファイルは永続化できないため、PostgreSQL（Neon / Vercel Postgres / Supabase）が必須です。`DATABASE_URL` または `POSTGRES_URL` を環境変数に設定してください。未設定の場合は API が 500 エラーになります。

### 本番起動（Vercel）

```bash
npm run build
npm start
```

定期巡回を有効にする場合は `.env` に以下を設定してください。

```
ENABLE_CRON=true
```

## 使い方

### 1. 監視URLの登録

1. 「監視サイト管理」を開く
2. 各店舗の「編集」をクリック
3. **監視対象URL** を入力（例: お知らせページ、抽選情報ページ）
4. 「有効」にチェックを入れて保存
5. 「今すぐ巡回」で動作確認

> URLが不明な店舗は、仮URLを作らず未設定のままにしています。公式サイトのお知らせページ等を調べて登録してください。

### 2. 抽選情報の確認

「抽選情報一覧」で検出された情報を確認できます。

- 初期表示: **未確認** のみ、締切が近い順
- 各カードから「応募予定」「応募済み」「対象外」に変更可能
- 「手動追加」でURLを貼り付けて解析・登録

### 3. ダッシュボード

- 「全サイトを今すぐ巡回」で一括巡回
- 新着件数、締切件数、エラー件数を確認

### 4. 設定

- 検出キーワード・除外キーワードの編集
- 通知のON/OFF
- 信頼度の最低表示値、保存期間

## 技術構成

| 項目 | 技術 |
|------|------|
| フロントエンド | Next.js 14 (App Router) + React |
| 言語 | TypeScript |
| DB | ローカル: SQLite / Vercel: PostgreSQL（postgres） |
| ページ取得 | fetch + cheerio |
| 定期実行 | node-cron |
| 日時解析 | date-fns |

## 環境変数（将来の拡張用）

`.env.example` を参照してください。

- `DATABASE_URL` / `POSTGRES_URL` — PostgreSQL接続文字列（**Vercel本番で必須**）
- `DATABASE_PATH` — ローカル開発時のSQLiteファイルパス（省略可）
- `ENABLE_CRON` — 定期巡回の有効化
- `X_API_BEARER_TOKEN` — X API（未実装）
- `DISCORD_WEBHOOK_URL` — Discord通知
- `LINE_NOTIFY_TOKEN` — LINE通知

## 制約・注意事項

- XやGoogle検索の直接スクレイピングは行いません
- ログイン必須・CAPTCHA付きページは取得しません
- 取得失敗は巡回履歴にエラーとして記録されます
- サンプルデータには「サンプル」バッジが付きます
- 見逃し防止のため、信頼度が低い情報も「要確認」として残します

## 現時点で取得可能な情報源

- **ユーザーが登録した公開Webページ**（HTML）— お知らせページ、抽選案内ページなど
- **手動登録** — 任意のURLを貼り付けて解析

## 取得できない情報源と理由

| 情報源 | 理由 |
|--------|------|
| X（Twitter）の投稿 | APIキー未設定。直接スクレイピングは規約上非推奨のため未実装 |
| Google検索結果 | 規約・CAPTCHAのため未実装 |
| ログイン必須ページ | 認証情報を扱わない設計のため |
| CAPTCHA付きページ | 回避しない方針のため |
| URL未設定の店舗 | 仮URLを作らない設計のため |
